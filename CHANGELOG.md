# Changelog

## 1.0.0 - 2026-11-15

First packaged GitHub release. Public versioning starts at 1.0.0; the earlier
0.x builds were development previews.

- Native local text/emoji font import, preview, Apply and system-default Restore.
- Installed icon packs, per-app artwork, batch review and original-icon recovery.
- Local Vivo themes, component selection and a retained first-setup recovery backup.
- Icon-test confirmation that remembers and continues the requested change.
- Native transparent-icon calibration for supported 1x1 rendering.
- Device capability reports with manual export and bounded private history.
- One universal APK for ARM64, ARM32, x86-64 and x86, with native changes still
  restricted to compatible ARM64 Vivo/iQOO phones.
- Cleaned documentation, private signing configuration and development-file exclusions.

Device scope remains limited to the documented Chinese-ROM X200 Ultra profile.
Other models/Global ROMs and the newly packaged non-ARM64 runtimes are unverified.
